## 一、作品定位

**墨灵 VelaInk** 是一款把 AI 创作落到纸面的书写绘画机器人：用户说一句"画一只小猫"或"用行书写一首诗"，系统自动理解意图、规划构图、生成笔触轨迹，并在真实纸张上**物理书写**出来。

它不是"人操作机器"的 GUI 工具，而是"机器理解人"的 AI Agent——从工具到智能体的产品形态跃迁。

## 二、解决的真实痛点

- **想得到、画不出**：数字 AI 创作停留在屏幕里，无法产出有手感的实体作品
- **断网就废**：云端 AIGC 依赖网络，隐私与可用性双输
- **千篇一律无温度**：打印/雕刻没有真实笔迹的书写质感

## 三、系统架构：三层解耦

```
用户语音/文字
  → ① AI 创作层：意图理解 + 轨迹生成（LLM 输出 SVG 骨架 → Catmull-Rom 插值补密）
  → ② openvela 实时层：VELAINK/1 协议收发笔迹数据 → StrokeCompiler 编译 G-code
  → ③ 运动执行层：自研写字机（GRBL 固件 + CoreXY 运动学 + Z 轴抬笔）
  → 真实纸面书写
```

| 层 | 实现 | 说明 |
|---|---|---|
| AI 创作层 | velaink_brain.py（LLM + SVG 骨架生成 + 插值） | 双引擎：A=LLM 直出骨架（4~8 控制点/笔），B=文生图线稿矢量化 |
| openvela 实时层 | goldfish 模拟器运行 openvela（NuttX 内核）+ velaink 应用三件套（stroke/gcode/protocol） | VELAINK/1 自定义协议；send-response 流控适配 GRBL 128 字节缓冲；AI 笔迹数据直接存入 openvela 文件系统并由 NSH 读取（见演示视频） |
| 运动执行层 | 自研写字机 200×196mm | CoreXY 插补、梯形加减速、限位保护、笔尖对零，GRBL 1.1f |

## 四、核心功能

1. **自然语言生成绘画/书写（MVP）**：一句话 → SVG 骨架 → 插值 → G-code → 真机书写
2. **双引擎轨迹生成**：LLM 只出语义骨架、曲线精度交给确定性算法——解决"AI 直出坐标必抖动"的行业难题（已实测验证）
3. **G-code 编译器（StrokeCompiler，自研）**：三段式输出、空移/书写双速分离、逐笔抬落笔
4. **GRBL 流控驱动（GrblDriver，自研）**：发一行等 `ok`、`?` 状态轮询、ALARM 处理、`$H` 回零
5. **openvela 实时层设计**：VELAINK/1 协议 + openvela 应用三件套（已入仓），分层解耦支持后续端侧 AI 加速演进
